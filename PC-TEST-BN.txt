PC-তে পরীক্ষা (v63)

1. ZIP Extract করুন। Extract করা ফোল্ডারের RUN-LOCAL-WINDOWS.bat ডাবল ক্লিক করুন।
2. Node.js এবং Python 3 লাগবে। প্রথমবার npm ci চালানোর জন্য ইন্টারনেট লাগবে।
3. Build শেষ হলে ব্রাউজার নিজে খুলবে। না খুললে CMD-তে দেখানো 127.0.0.1 URL খুলুন।
4. প্রথমবার Login/Signup-এ নতুন স্থানীয় account খুলুন। Render-এর account এই PC-তে স্বয়ংক্রিয়ভাবে থাকবে না।
5. Groq key লিখে 'Groq key পরীক্ষা' চাপুন। 403 হলে সম্পূর্ণ error message দেখুন, কিন্তু key পাঠাবেন না।
6. সার্ভার বন্ধ করতে CMD-তে Ctrl+C চাপুন।

এই ZIP-এ আপনার Render database বা saved account নেই। Account এই ফোল্ডারে users.sqlite3-এ জমা হয়।
